# TaskNet Language Support

Syntax highlighting and language support for TaskNet files (.tn) used in MEXEC tasknets.

## Features

- Syntax highlighting for TaskNet DSL
- Support for tasknet keywords, types, and operators
- Comment highlighting (both `#` and `//` styles)
- String highlighting
- Auto-commenting with Cmd+/ or Ctrl+/ (uses `//`)

## Usage

Open any file with `.tn` extension to activate syntax highlighting.
