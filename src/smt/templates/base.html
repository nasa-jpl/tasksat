Using the TaskSAT Web UI

The web UI is a front end for the SMT verifier (src/smt/tasknet_verifier.py). It runs on your machine and works directly with the .tn files on your disk.

Home page
  • Create New Tasknet — write a new .tn file in the built-in editor, choose a folder, and verify it.
  • Open File — browse your filesystem and pick an existing .tn file. Then either Run Verification, or Add without running to list it now and verify later.
  • View Report — open a tasknet's schedule, timelines, property results, and (for UNSAT) the conflict analysis.
  • Delete (per card) / Delete All Reports — remove verification results. Your original .tn source files are never deleted.
Report page
  • Edit & save — edits are written back to the original .tn file, in place. There are no copies.
  • Re-verify / Save & Verify — re-run the verifier, optionally in a different mode or with extra checks.
  • Mode — Optimize finds the best schedule; Satisfy finds any valid schedule (faster).
  • Realizability — check that every allowed initial state admits some valid schedule.
  • Compositional — check that one session preserving an invariant P implies any-length sequence preserves it (needs an invariant {…} block).
Cancelling

While a verification is running, a banner appears at the top of the page with a Cancel button that stops the run.
