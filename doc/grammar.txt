# TaskSAT Grammar Reference

## Top-Level Structure

```
tasknet <identifier> {
  end = <number>;
  timelines { ... }
  initial { ... }
  taskdef <name> { ... }
  task <name> : <taskdef> { ... }
  constraints { ... }
  properties { ... }
}
```

## Timelines

```
<name> : state(<state1>, <state2>, ...) = <initial_state>;
<name> : atomic = <true|false>;
<name> : cumulative [<min>, <max>] bounds [<min>, <max>] = <initial>;
<name> : rate [<min_rate>, <max_rate>] bounds [<min>, <max>] = <initial> initial_rate = <rate>;
<name> : claimable [<min>, <max>] = <initial>;
```

## Tasks

```
taskdef <name> {
  id <number>;
  priority <number>;
  duration <number>;
  duration_range [<min>, <max>];
  start <number>;
  start_range [<min>, <max>];
  after <task_or_taskdef>, ...;
  containedin <task_or_taskdef>, ...;
  pre { <constraints> }
  inv { <constraints> }
  post { <constraints> }
  impacts {
    pre { <impacts> }
    maint { <impacts> }
    post { <impacts> }
  }
}

task <name> : <taskdef> { ... }
optional task <name> : <taskdef> { ... }
request task <name> : <taskdef> { ... }
```

## Constraints

```
<timeline> = <value>
<timeline> in [<min>, <max>]
<timeline> < <number>
<timeline> <= <number>
<timeline> > <number>
<timeline> >= <number>
```

## Impacts

```
<timeline> = <value>
<timeline> += <delta>
<timeline> +~ <delta>
<timeline> =~ <value>
```

## Temporal Logic

### Atomic Formulas
```
true
false
<timeline> = <value>
<timeline> in [<min>, <max>]
<timeline> <op> <number>
active(<task>)
```

### Logical Operators
```
not <formula>
<formula> and <formula>
<formula> or <formula>
<formula> -> <formula>
```

### Temporal Operators
```
always <formula>
eventually <formula>
<formula> until <formula>
sofar <formula>
once <formula>
<formula> since <formula>
```

### Sequential Ordering
```
sequence [<task1>, <task2>, ...]
```

Syntactic sugar for sequential task execution. Desugars to pairwise `.end <= .start` constraints.

### Constraints vs Properties
```
constraints {
  prop <name>: <formula>;
}

properties {
  prop <name>: <formula>;
}
```

## Dependencies

```
after <task_id>, ...;
containedin <task_id>, ...;
```

## Comments

TaskSAT supports both hash and C-style line comments:

```tasknet
# This is a hash-style comment
// This is a C-style comment

tasknet Example {
  end = 100;  # Inline hash comment

  timelines {
    battery : rate [0.0, 100.0] = 50.0;  // Inline C-style comment
  }
}
```

Both comment styles can be used interchangeably. C-style `//` comments are useful for block commenting in editors like VS Code (Cmd+/ or Ctrl+/).

## Example

```tasknet
tasknet RoverMission {
  end = 1000;

  timelines {
    battery : rate [0.0, 100.0] bounds [0.0, 100.0] = 50.0 initial_rate = 0.01;
    location : state(base, site_a, site_b) = base;
    rover_active : atomic = false;
  }

  taskdef drive {
    duration_range [10, 50];
    pre {
      battery >= 30.0;
      rover_active = false;
    }
    inv {
      battery >= 20.0;
      rover_active = true;
    }
    impacts {
      maint {
        battery -~ 0.5;
        rover_active += 1.0;
      }
    }
  }

  task drive_to_a : drive {
    start_range [0, 100];
    impacts {
      post {
        location = site_a;
      }
    }
  }

  properties {
    prop battery_safety:
      always (rover_active = true -> battery >= 20.0);

    prop mission_completion:
      eventually (location = site_a);
  }
}
```
